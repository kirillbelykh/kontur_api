# Эксплуатация и диагностика

Установка, запуск и обновление описаны в [README.md](../README.md).
Здесь — что делать, когда что-то не так.

## Сессия Контура

«Сессия активна» появляется только после проверки cookies живым запросом
`GET /api/v1/user` — не по возрасту локального файла. Кнопка «Обновить сессию»
проходит полный путь: файл → профиль Яндекс Браузера → Selenium (фоновое окно
за экраном, скрытое через Win32).

Если Контур отдаёт ошибки авторизации:

1. Нажмите «Обновить сессию» и дождитесь результата.
2. Убедитесь, что в обычном Яндекс Браузере выполнен вход в Контур —
   Selenium использует этот профиль (`KONTUR_YANDEX_PROFILE` в `.env`,
   по умолчанию профиль подбирается автоматически).
3. Несовместимый `driver\yandexdriver.exe` приложение чинит само
   (`scripts\ensure_yandex_driver.ps1`); вручную:
   `powershell -File scripts\ensure_yandex_driver.ps1 -Force`.
4. Сбор cookies идёт в отдельном профиле программы
   (`runtime\auth\yandex_profile`), обычный Яндекс Браузер закрывать не нужно.

Логи: `runtime\logs\lookup.log`.

## Обновления

- Кнопка «Обновить» не появляется: приложение должно стоять из git-клона
  (копия из exe-установщика не обновляется), а ветка не должна расходиться
  с `origin/main` — обновление идёт только fast-forward.
- Обновление упало или окружение сломалось: `Update.bat`, либо `git pull`
  и затем `Install.bat` / `Install.exe` (лог: `runtime\logs\kontur_update.log`).

## Печать

- BarTender установлен, принтер выбран на экране «Печать этикеток».
- Шаблоны лежат в `assets\labels\100x180` и `assets\labels\100x136`.
- Если задание появляется и исчезает — проверьте BarTender, доступность
  принтера и значения полей шаблона.

## Ярлык

Ярлык «Контур Маркировка» пересоздаётся приложением при каждом запуске.
Если он сломан и приложение не стартует — снова `Install.bat` / `Install.exe`.

## Очистка runtime-файлов

```powershell
.\scripts\clean_runtime.ps1 -WhatIf   # показать, что будет удалено
.\scripts\clean_runtime.ps1
```

Скрипт удаляет только типовые runtime-файлы и не трогает то, что
отслеживается git.
