# Эксплуатация

## Установка На Новый ПК

1. Склонируйте репозиторий.
2. Запустите `setup.bat`.
3. Убедитесь, что установлены BarTender, CryptoPro/CAdES и сертификат.
4. Запустите `KonturTestAPI` и нажмите `Обновить сессию`, если авторизация не
   подтянулась автоматически.

## Обновление

Используйте ярлык `Обновление`. Он должен подтянуть `main`, синхронизировать
зависимости и пересобрать локальные ярлыки/служебные файлы.

## Сессия Контура

При старте приложение обновляет cookies в фоне через пакет `auth`.

Важно:

- Сообщение «Сессия активна» появляется только после проверки cookies через
  Kontur API (`/api/v1/user`), а не только из локального файла.
- Если локальные/профильные cookies мертвы, приложение собирает cookies через
  Selenium в фоновом режиме (окно скрыто / за экраном), как раньше.
- Для настоящего Chrome headless можно поставить `KONTUR_BROWSER_HEADLESS=1`.
- Кнопка «Обновить сессию» проходит тот же путь (файл → профиль → браузер).

Если Контур отдает ошибки авторизации:

1. Нажмите «Обновить сессию».
2. Убедитесь, что в обычном Yandex Browser вы уже залогинены в Контур
   (Selenium использует этот профиль).
3. Проверьте, что `driver/yandexdriver.exe` совместим с Yandex Browser.
4. Проверьте профиль (`KONTUR_YANDEX_PROFILE` или профиль из Local State).

## Печать

- Проверьте, что принтер выбран в табе `Печать этикеток`.
- Убедитесь, что нужный шаблон есть в папках BarTender.
- Если задание появляется и исчезает, проверьте BarTender, доступность принтера
  и значения полей шаблона.

## Очистка Runtime-Файлов

Для безопасной уборки локального мусора используйте:

```powershell
.\scripts\clean_runtime.ps1 -WhatIf
.\scripts\clean_runtime.ps1
```

Скрипт удаляет только типовые runtime-файлы и пропускает файлы, которые уже
отслеживаются Git.
